Cómo publicarlo en vivo

  1. Haz una edición del archivo data/maratonsc-data.json.
  2. Rellena el marcador de cada encuentro terminado en status: finished.
  3. Haz commit y push al repositorio: GitHub Pages refrescará la página automáticamente.

Esta versión funciona sin API: todo viene del archivo local data/maratonsc-data.json.
